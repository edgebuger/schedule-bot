# Бот с расписанием ВСАМК

Телеграм-бот, который присылает расписание пар группы **ОММ-102**.
Работает на GitHub Actions — компьютер выключен, бот всё равно работает.

## Как устроено

```
Крон в GitHub Actions (раз в 10 минут)
        │
        ├─ раз в день, начиная с 06:00 Екатеринбург → присылает расписание
        │
        └─ при любом запуске               → отвечает на команды
```

Команды отвечаются с задержкой до ~10 минут — это цена бесплатного хостинга.
Само расписание приходит в 06:00 по Екатеринбургу (плюс возможная задержка
запуска крона).

Состояние (подписчики, что уже отправлено) лежит в `state.json` и коммитится
обратно в репозиторий. Поэтому база данных не нужна.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | подписаться на рассылку |
| `/today` | расписание на сегодня |
| `/tomorrow` | на ближайший опубликованный день |
| `/all` | на неделю |
| `/off` | отключить рассылку |
| `/on` | включить обратно |
| `/help` | справка |

Если день ещё не опубликован на сайте — бот так и скажет и назовёт ближайшую дату.
Замены помечаются: 🔁 замена, 🆕 добавлено, ❌ отменена.

## Откуда данные

У сайта ВСАМК есть REST API, который отдаёт всё расписание одним запросом:

```
https://vsamk.ru/wp-json/vsamk-schedule/v1/current
```

HTML не парсится, поэтому бот не ломается от редизайна сайта.
Время звонков (08:00–09:20 и дальше) подставляется из `BELLS` в `config.py`.

## Настройки

Всё задаётся в `.github/workflows/bot.yml`:

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `BOT_TOKEN` | — | токен от @BotFather, лежит в Secrets |
| `GROUP` | `ОММ-102` | группа, пары которой присылать |
| `SEND_TIME` | `06:00` | время рассылки (по TIMEZONE) |
| `TIMEZONE` | `Asia/Yekaterinburg` | часовой пояс, в котором считается SEND_TIME |
| `COLLEGE_TIMEZONE` | `Asia/Yekaterinburg` | по нему считается «сегодня» |
| `SEND_ON_WEEKENDS` | `0` | `1` — слать и в воскресенье |

## Как поменять группу

Открой `.github/workflows/bot.yml`, найди `GROUP: 'ОММ-102'`, поменяй на свою
(например `ОММ-101`), закоммить. Больше ничего трогать не надо.

## Проверка

Запусти вручную: вкладка **Actions** → **Бот с расписанием ВСАМК** →
**Run workflow**. Галочка «Разослать расписание прямо сейчас» пришлёт
расписание минуя ожидание 06:00.

## Если расписание не приходит

1. Открой **Actions** → кликни на последний запуск → **Run bot** →
   там видно, что именно сломалось.
2. Чаще всего виноват токен в **Settings → Secrets and variables → Actions**.
